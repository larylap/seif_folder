# Сейф — установка на iPhone

Приложение — это 5 файлов (index.html, sw.js, manifest.json, icon-180.png, icon-512.png).
Их нужно один раз выложить на любой бесплатный хостинг с https, открыть в Safari
и добавить на экран «Домой». После этого интернет не нужен.

## Шаг 1. Выложить файлы (один раз, 5 минут, бесплатно)

**Вариант А — GitHub Pages**
1. Зарегистрируйтесь на github.com.
2. New repository → любое имя (например `seif`) → Create.
3. «uploading an existing file» → перетащите 5 файлов → Commit.
4. Settings → Pages → Branch: `main` → Save.
5. Через минуту появится адрес вида `https://ВАШ-ЛОГИН.github.io/seif/`.

**Вариант Б — Cloudflare Pages / Netlify**
Зарегистрируйтесь и перетащите папку с файлами в окно «Deploy». Получите адрес.

Код на хостинге не содержит ничего секретного: файлы и пароль туда никогда не попадают.

## Шаг 2. Установить на iPhone
1. Откройте адрес **в Safari**.
2. «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запустите «Сейф» **с иконки** и только там придумайте пароль.
   (Safari и установленное приложение хранят данные раздельно.)

## Как это работает
- Пароль → PBKDF2 (600 000 итераций) → ключ, которым зашифрован случайный ключ AES-256.
- Каждый файл, его имя и миниатюра шифруются AES-GCM и лежат только в памяти iPhone.
- Пароль нигде не сохраняется. Забыли пароль — данные не восстановить.
- После 5 неверных попыток — нарастающая пауза.
- Автоблокировка при сворачивании и после простоя (настраивается).

## Важно
- **Удалите иконку приложения — удалятся и все данные.** Делайте резервную копию:
  Настройки → «Сохранить копию в файл» (файл `.safe` зашифрован тем же паролем).
- Добавленные в сейф фото не удаляются из «Фото» автоматически — удалите оригиналы сами.
- Очень большие видео (больше ~700 МБ) телефон может не потянуть при шифровании.
- «Поделиться / сохранить» выводит файл из сейфа уже расшифрованным.

## Обновление
Если меняете файлы — увеличьте номер в `sw.js` (`seif-v1` → `seif-v2`), загрузите заново,
откройте приложение с интернетом два раза.
